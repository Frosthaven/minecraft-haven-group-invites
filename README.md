# haven-group-invites

MMO-style groups for the Haven Minecraft server (NeoForge 1.21.1): invite players from the Social Interactions screen or with `/invite`, share claims through FTB Teams and FTB Chunks, group chat with `/g`, and group health frames on the HUD.

Status: design. See [DESIGN.md](DESIGN.md) and the mockups in `docs/mockups/index.html`.
